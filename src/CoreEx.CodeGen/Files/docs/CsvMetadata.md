# CSV metadata settings



## Properties
The `CsvMetadata` object supports a number of properties that control the generated code output. The following properties with a bold name are those that are more typically used (considered more important).

Property | Description
-|-
`position` | Metadata position. Valid options are: `Any`, `First`, `Last`.<br/>&dagger; Defaults to Any; blank/comment records and the column-name header do not count.
